# ZigZag Clone (for Desktop)

[![Unity Version](https://img.shields.io/badge/Unity-2020.3.25f1-blue.svg?style=flat&logo=unity)](https://unity.com/)
[![Language](https://img.shields.io/badge/Language-C%23-green.svg?style=flat&logo=c-sharp)](https://learn.microsoft.com/en-us/dotnet/csharp/)
[![Platform](https://img.shields.io/badge/Platform-Windows-orange?logo=windows)](https://www.microsoft.com/windows/)

A polished, desktop-friendly clone of the famous hypercasual mobile game **ZigZag**.

Stay on the platform, collect crystals, unlock new skins, and try not to fall off!

---

## 🚀 Quick Start

Want to skip the code and just play? 
1. **[Download the Repository](https://github.com/Frext/zigzag-game-clone/archive/refs/heads/main.zip)**
2. Extract the ZIP file.
3. Open the **`ReleaseBuild`** folder and launch **`Zigzag Clone.exe`**.

---

## ✨ Features

*   **Classic Mechanics:** Simple, one-click control to change direction.
*   **In-Game Shop:** Collect crystals during your runs to unlock custom ball skins.
*   **Local Save System:** Persists your high score, total crystals and unlocked skins across sessions.
